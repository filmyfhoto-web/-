# คู่มือทดสอบบนมือถือ — ระบบสินค้า (Mobile QA Checklist)

ใช้ทดสอบหน้า `/admin/products`, `/staff/products/new`, `/receipts/*/master/products`, `/shop`
อัปเดตล่าสุด: 2026-06-30

## ก่อนเริ่ม

- เปิดเว็บแอพบนมือถือผ่าน Safari (iOS) หรือ Chrome (Android)
- ตรวจว่า PWA ติดตั้งได้: เมนู Share → "เพิ่มไปยังหน้าโฮม"
- เปิด DevTools remote (Chrome `chrome://inspect` / Safari Web Inspector) เพื่อตามดู console
- ใช้บัญชี: admin (filmy.fhoto@gmail.com), staff, customer test
- เตรียมตัวอย่างสินค้า: บาร์โค้ดจริง 5 ชิ้น, ฉลากภาษาไทย/อังกฤษ, รูปสินค้าหลังแสงปกติ

# คู่มือทดสอบ LIFF (ทีละขั้น)

ใช้เอกสารนี้ตรวจการผูก LINE / LIFF ของร้านให้พร้อมใช้งานจริง ทำตามลำดับ A → E แล้วเช็ก ☐ ตามช่อง "ผลที่ควรได้"

---

## ขั้นเตรียมก่อนทดสอบ

- [ ] มือถือที่ล็อกอิน LINE แล้ว (Android หรือ iOS)
- [ ] บัญชี LINE สำหรับทดสอบ (ถ้าเป็นไปได้ ใช้บัญชีที่ยังไม่เคยผูกร้าน)
- [ ] เข้าเว็บด้วยบัญชี **แอดมิน** ได้ (มีสิทธิ์เข้า `/admin/*`)
- [ ] เตรียมโดเมนที่จะทดสอบไว้ 2 อัน:
  - Production: `https://www.filmyynatta.com`
  - LIFF ID ปัจจุบัน: ดูที่ `/admin/line-settings`

---

## ขั้น A — ตรวจค่าคอนฟิก (ก่อนแตะมือถือ)

| # | สิ่งที่ต้องทำ | ผลที่ควรได้ | ☐ |
|---|---|---|---|
| A1 | เปิด `/admin/liff-check` → กด **ตรวจใหม่** | Badge ด้านบน "ผ่านทั้งหมด" (เขียว) หรืออย่างน้อย 0 problems | ☐ |
| A2 | เทียบ **Endpoint URL** ในการ์ดกับ LINE Developers Console → LIFF | ตรงกันเป๊ะ (protocol + host + path) | ☐ |
| A3 | เช็ก **Callback URLs** — ควรมีอย่างน้อย `https://www.filmyynatta.com/l/shop` และ `https://filmyynatta.com/l/shop` | ครบ ไม่มี "ขาด N รายการ" | ☐ |
| A4 | เปิด `/admin/line-settings` → การ์ด **สถานะ LIFF (สรุปเร็ว)** | ทั้ง 3 pill เขียว | ☐ |
| A5 | ส่งข้อความทดสอบผ่าน `/admin/line-settings` (ถ้ามีปุ่ม self-test) | LINE ของแอดมินได้รับข้อความ | ☐ |

**ถ้า A ไม่ผ่าน อย่าไปต่อขั้น B** — แก้ตามคำแนะนำในการ์ดก่อน (ปุ่ม 📋 คัดลอกค่าที่ถูกให้ไปวางใน LINE Console)

---

## ขั้น B — ทดสอบ auto-bind ครั้งแรก (มือถือ)

1. เปิด LINE บนมือถือ → เปิด URL `https://liff.line.me/<LIFF_ID>`
   หรือสแกน QR ที่ Console แสดง
2. รอ 1–2 วินาที

**ผลที่ควรได้:**
- ☐ เห็นหน้า loading "กำลังเชื่อมต่อ LINE..." สั้น ๆ
- ☐ เข้าหน้า `/shop` ได้ทันที (ไม่ต้องกรอกอะไร)
- ☐ ที่ `/admin/auto-bind-history` มีแถวใหม่ event = `liff_auto_bind_ok`

**ถ้าค้าง / เด้งกลับหน้าล็อกอิน:**
- กดปุ่ม **"พบปัญหาเข้าไม่ได้?"** บนหน้ากั้น → ทำตามคำแนะนำ 4 ข้อ
- ถ้ายังไม่หาย → กดปุ่ม **"คัดลอกรหัสข้อผิดพลาด"** ส่งให้ dev

---

## ขั้น C — ทดสอบเข้าซ้ำ (re-entry)

1. ปิด LIFF (กากบาทมุมขวาบน)
2. เปิด `https://liff.line.me/<LIFF_ID>` ใหม่อีกครั้ง

**ผลที่ควรได้:**
- ☐ **ไม่เจอ** หน้ากั้น "เข้าสู่ระบบด้วย LINE" อีก
- ☐ เข้า `/shop` ได้ทันที

ถ้ายังเจอหน้ากั้น → แสดงว่า `writeBinding()` ไม่ persist หรือ `hasBinding()` ไม่รู้จัก schema ที่บันทึกไว้ → เก็บ log แล้วแจ้ง dev

---

## ขั้น D — ทดสอบผูกเบอร์ (ดึงประวัติเก่า)

1. เข้า `/l/link` (หรือกดปุ่ม "ผูกด้วยเบอร์โทรแทน" บนหน้ากั้น)
2. กรอกเบอร์โทรที่มีในฐานข้อมูล (`rds_customers` หรือ `guest_customers`)
3. กด **เชื่อมบัญชี LINE**

**ผลที่ควรได้:**
- ☐ Toast เขียว "เชื่อมบัญชีสำเร็จ"
- ☐ ถูกพาไป `/shop` อัตโนมัติภายใน 1 วินาที
- ☐ ที่ `/my-orders` เห็นประวัติคำสั่งซื้อของเบอร์นั้น
- ☐ `/admin/line-recipients` (หรือ table `line_account_links`) — row ของ line_user_id นี้มี `phone` และ `customer_id` แล้ว

**เคสที่ต้องทดสอบเพิ่ม:**
- กรอกเบอร์ผิดรูปแบบ (`123`) → toast แดง "กรุณากรอกเบอร์โทรให้ถูกต้อง"
- กรอกเบอร์ที่ไม่มีในระบบ → ระบบสร้าง `guest_customers` ให้เอง ควรผูกสำเร็จเช่นกัน

---

## ขั้น E — ทดสอบสั่งซื้อครบวงจร

1. หน้า `/shop` → เพิ่มสินค้า 2 รายการเข้า cart
2. `/cart` → กด **ส่งคำสั่งซื้อ**
3. รอ notification

**ผลที่ควรได้:**
- ☐ ได้ order number
- ☐ LINE OA ส่งข้อความยืนยันเข้า LINE ของลูกค้าภายใน 10 วินาที
- ☐ แอดมินได้รับแจ้งเตือน order ใหม่ที่ LINE
- ☐ `/admin/orders` ขึ้นออเดอร์ใหม่ พร้อม line_user_id ถูกจับคู่

---

## ตารางอาการ ↔ สาเหตุ ↔ วิธีแก้

| อาการ | Event ใน log | สาเหตุจริง | วิธีแก้ |
|---|---|---|---|
| เด้งไปโดเมนอื่นทันทีตอนเปิด LIFF | `liff_redirect` (reason: `origin_mismatch`) | เปิดจากโดเมนที่ไม่ตรงกับ Endpoint | เปิดจากโดเมนที่ตั้งใน LIFF Endpoint เท่านั้น หรือเพิ่มโดเมนเข้า Callback |
| หน้า loading ค้าง / เห็น error | `liff_init_fail` | LIFF SDK init ล้มเหลว (LIFF ID ผิด / channel ผิด) | ตรวจ LIFF ID ใน `/admin/line-settings` |
| เข้าแล้วเด้งกลับหน้ากั้นซ้ำ | `liff_login_loop` | `hasBinding()` มองไม่เห็น line_user_id ที่บันทึก | กดปุ่ม "ล้างข้อมูลแล้วเริ่มใหม่" แล้วลองใหม่ |
| ผูกเบอร์ไม่ผ่าน | `link_verify_fail` | เบอร์ผิดรูปแบบ / edge function error | ดูคอลัมน์ "เหตุผล" ใน `/admin/auto-bind-history` |
| Auto-bind fail | `liff_auto_bind_fail` | line-link-bind edge function พัง | ตรวจ Supabase function logs |
| ได้เข้า `/shop` แต่ไม่มีประวัติเก่า | — | ยังไม่ผูกเบอร์ (auto-bind มีแค่ line_user_id) | ไป `/l/link` กรอกเบอร์ |

---

## จุดเก็บ log ที่ควรดู

- `/admin/liff-check` — สถานะปัจจุบัน + auto-refresh
- `/admin/auto-bind-history` — ประวัติทุก event, มีปุ่ม **ส่งออก CSV / JSON**
- `/admin/line-webhook-events` — webhook ที่รับเข้ามาจาก LINE OA
- Supabase → `line_login_diagnostics` — ตาราง raw log
- Supabase → `line_account_links` — ตารางสถานะการผูก

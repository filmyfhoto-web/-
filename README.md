# nattafilmyy

สร้างเว็บแอพ/PWA ภาษาไทยสำหรับร้านค้า ชื่อ “ระบบสั่งซื้อและจัดซื้อสินค้า” ใช้งานได้บนมือถือ แท็บเล็ต และคอมพิวเตอร์ หน้าตาคล้ายระบบเบิกพัสดุในภาพตัวอย่าง: โทนแดง-ชมพูไล่เฉด พื้นหลังชมพูอ่อน การ์ดสินค้าแบบมีรูปสินค้า ปุ่มสีชมพู มุมโค้ง เงาเบา อ่านง่ายสำหรับทุกคน

วัตถุประสงค์: ลูกค้า เช่น โรงเรียน สำนักงาน หรือหน่วยงานต่าง ๆ สามารถเลือกสินค้า ใส่จำนวน ส่งรายการสั่งซื้อ/ขอราคาให้ร้านได้ ร้านสามารถใส่ราคาตามลูกค้าแต่ละราย อนุมัติรายการ ทำเอกสาร และส่งออกไฟล์ตาราง CSV/Excel-compatible สำหรับเปิดใน Google Sheets ได้

บทบาทผู้ใช้:
1. เจ้าของร้าน: จัดการทุกอย่าง
2. แอดมินร้าน: จัดการสินค้า ออเดอร์ ราคา สต๊อก และรายงาน
3. ลูกค้า: เห็นเฉพาะข้อมูลของตัวเอง เลือกสินค้า ส่งรายการ ดูสถานะ และดาวน์โหลดเอกสาร

หน้าจอที่ต้องมี:
- หน้าแรกแบบการ์ด 3 ช่อง: เข้าสู่ระบบลูกค้า, สมัครสมาชิก/หน่วยงาน, แอดมิน
- หน้าสมัครสมาชิก/หน่วยงาน: ชื่อหน่วยงาน ชื่อผู้ติดต่อ เบอร์โทร อีเมล LINE ID ที่อยู่ ประเภทลูกค้า
- หน้าลูกค้าเลือกสินค้า: ค้นหา หมวดหมู่ การ์ดสินค้า รูป ชื่อ รหัส สต๊อก หน่วยนับ จำนวน ปุ่มเพิ่มลงตะกร้า
- หน้าตะกร้า: แก้จำนวน ลบรายการ หมายเหตุ ส่งรายการให้ร้าน
- ประวัติคำสั่งซื้อของลูกค้า: เลขที่ วันที่ สถานะ ยอดรวม หมายเหตุ
- รายละเอียดคำสั่งซื้อ พร้อมปุ่มดาวน์โหลดเอกสารเมื่อมีเอกสารแล้ว
- Dashboard แอดมิน: สินค้าทั้งหมด ลูกค้าทั้งหมด ออเดอร์วันนี้ รอเสนอราคา รออนุมัติ สินค้าใกล้หมด ยอดรวมเดือนนี้ จำนวนการเข้าใช้งานวันนี้แบบสรุป
- จัดการสินค้า: เพิ่ม/แก้ไข/ลบสินค้า อัปโหลดรูป รหัสสินค้า ชื่อสินค้า หมวดหมู่ หน่วยนับ สต๊อกคงเหลือ จุดเตือนสต๊อกต่ำ ราคาทุน ราคามาตรฐาน เปิด/ปิดขาย
- จัดการลูกค้า/หน่วยงาน: อนุมัติสมาชิก กำหนดกลุ่มราคา แก้ข้อมูลลูกค้า
- จัดการราคา: ราคามาตรฐาน ราคาตามกลุ่มลูกค้า ราคาพิเศษรายลูกค้า โดยใช้ลำดับ ราคาพิเศษรายลูกค้า > ราคากลุ่มลูกค้า > ราคามาตรฐาน > รอร้านเสนอราคา
- จัดการออเดอร์: ดูรายการ ใส่ราคา แก้ส่วนลด ค่าจัดส่ง หมายเหตุ เปลี่ยนสถานะ
- สถานะออเดอร์: รอเสนอราคา, เสนอราคาแล้ว, ลูกค้าอนุมัติแล้ว, กำลังจัดสินค้า, พร้อมรับ/พร้อมส่ง, เสร็จสิ้น, ยกเลิก
- จัดซื้อเข้าร้าน: สร้างใบจัดซื้อ เลือกสินค้า จำนวน ราคาทุน สถานะรอสั่ง/สั่งแล้ว/รับเข้าแล้ว และเมื่อรับเข้าแล้วเพิ่มสต๊อก
- ประวัติสต๊อก: รับเข้า จ่ายออก ปรับปรุง พร้อมผู้ทำรายการและเวลา
- รายงาน: รายงานออเดอร์ รายงานสินค้า รายงานลูกค้า รายงานสต๊อก สินค้าใกล้หมด พร้อมปุ่มส่งออก CSV
- ตั้งค่าระบบ: ชื่อร้าน โลโก้ ข้อมูลติดต่อ เลขเอกสาร ปุ่มใส่ลิงก์ LINE Official Account ปุ่มใส่ลิงก์ Google Apps Script Webhook สำหรับส่งข้อมูลไป Google Sheets ในอนาคต
- ศูนย์แจ้งเตือนในระบบ: แจ้งเตือนออเดอร์ใหม่ แจ้งเตือนเสนอราคาแล้ว แจ้งเตือนสินค้าใกล้หมด และมีปุ่มเปิด LINE Official Account เพื่อติดต่อแอดมิน

เอกสารที่ต้องออกได้:
- ใบเสนอราคา PDF
- ใบสั่งซื้อ PDF
- ใบส่งของ PDF
เอกสารมีโลโก้ร้าน ชื่อร้าน ข้อมูลลูกค้า เลขที่เอกสาร วันที่ ตารางสินค้า จำนวน หน่วย ราคา รวม หมายเหตุ และช่องลายเซ็น

โครงสร้างข้อมูล:
- users/profiles: ชื่อ อีเมล เบอร์โทร บทบาท สถานะ หน่วยงาน
- organizations: ชื่อหน่วยงาน ประเภท ผู้ติดต่อ เบอร์ อีเมล ที่อยู่ กลุ่มราคา สถานะ
- categories: ชื่อหมวดหมู่
- products: รหัสสินค้า ชื่อ หมวดหมู่ รายละเอียด หน่วย รูปภาพ สต๊อก จุดเตือนสต๊อกต่ำ ราคาทุน ราคามาตรฐาน สถานะเปิดขาย
- price_groups: ชื่อกลุ่มราคา
- group_prices: ราคาสินค้าตามกลุ่ม
- customer_prices: ราคาสินค้าเฉพาะหน่วยงาน
- orders: เลขที่ออเดอร์ หน่วยงาน ลูกค้า สถานะ ยอดรวม ส่วนลด ค่าจัดส่ง หมายเหตุ วันที่
- order_items: สินค้า จำนวน หน่วย ราคา รวม หมายเหตุ
- purchase_orders และ purchase_order_items
- stock_movements
- documents
- notifications
- activity_logs สำหรับบันทึกกิจกรรมสำคัญ เช่น เข้าระบบ แก้ราคา แก้สินค้า เปลี่ยนสถานะ

ข้อกำหนดระบบ:
- มี authentication และ role-based access control
- ลูกค้าเห็นเฉพาะข้อมูลของตัวเอง
- แอดมินเท่านั้นที่เห็นข้อมูลลูกค้าทั้งหมดและจัดการราคาได้
- บันทึกประวัติการแก้ไขสินค้า ราคา สต๊อก และสถานะออเดอร์
- ส่งออกข้อมูล CSV ที่เปิดใน Excel หรือ Google Sheets ได้
- ทำเป็น MVP ที่พร้อมทดสอบ flow: สมัครลูกค้า -> แอดมินอนุมัติ -> ลูกค้าเลือกสินค้า -> ส่งออเดอร์ -> แอดมินใส่ราคา -> สร้างเอกสาร -> ส่งออก CSV

ข้อมูลตัวอย่าง:
- สินค้า: ปากกาน้ำเงิน, ปากกาแดง, กระดาษ A4, แฟ้ม, เทปกาว, กาว, ถ่ายเอกสารขาวดำ, ปริ้นสี A4
- ลูกค้า: โรงเรียนบ้านครูดา, สำนักงานตัวอย่าง, ลูกค้าทั่วไป
- กลุ่มราคา: โรงเรียน, สำนักงาน, ทั่วไป
- ใส่ราคาตัวอย่างให้แต่ละกลุ่มต่างกัน

ใช้ภาษาไทยทั้งหมด ฟอนต์ไทยอ่านง่าย เช่น Sarabun หรือ Noto Sans Thai ทำ responsive จริง และเน้นใช้งานง่ายมาก

# รวมหน้า "ประวัติคำสั่งซื้อ" เข้ากับหน้า "ฉัน"

## สิ่งที่ตรวจพบ (ยืนยันจากโค้ดจริง)
- หน้า "ประวัติคำสั่งซื้อ" จริง ๆ คือ `src/pages/MyOrders.tsx` ที่ route `/my-orders` (มีตัวกรองสถานะ 5 ช่อง, กลุ่มลิงก์ "บัญชีของฉัน" 6 อัน, ค้นหา/กรองวันที่, รายการเต็ม)
- หน้า "ฉัน" คือ `src/pages/MyAccount.tsx` ที่ route `/my-account`
- **ยังไม่มี route `/account/orders` ในระบบ** — ลิงก์ในข้อความ LINE เดิม (`supabase/functions/send-order-line-notifications/index.ts:175` ส่ง `${site}/account/orders?order=<id>`) ตกไปหน้า NotFound อยู่ตอนนี้ แผนนี้จะทำให้ลิงก์นั้นใช้งานได้
- กล่อง "รายการล่าสุดของฉัน" อยู่ใน `src/components/account/AccountActionPanel.tsx`
- `/my-orders/:id` (รายละเอียดออเดอร์) เป็นคนละหน้า จะไม่แตะ — ลิงก์แจ้งเตือนแบบเก่าที่ชี้ `/my-orders/:id` ยังทำงานเหมือนเดิม

## สิ่งที่จะทำ
1. แยกเนื้อหาของ `MyOrders.tsx` (ตั้งแต่แถบสถานะ 5 ช่อง, กลุ่มลิงก์บัญชี 6 อัน, ตัวกรอง/ค้นหา, รายการออเดอร์, dialog ผูก LINE) เป็นคอมโพเนนต์ใหม่ `src/components/account/MyOrdersPanel.tsx` โดย **ย้ายโค้ดเดิมทั้งก้อน ไม่แก้ตรรกะ** (ตัด header โปรไฟล์ซ้ำและ breadcrumb ออก เพราะหน้า "ฉัน" มีอยู่แล้ว)
2. เรียก `<MyOrdersPanel />` ในหน้า `MyAccount.tsx` ต่อจากปุ่ม สั่งสินค้า / ทำใบเบิก / ส่ง Excel
3. ลบกล่อง "รายการล่าสุดของฉัน" (พร้อมการโหลด unified history ที่ใช้เฉพาะกล่องนี้) ออกจาก `AccountActionPanel.tsx` เหลือปุ่มหลัก 3 ปุ่ม + ปุ่ม "ดูประวัติทั้งหมด"
4. Routes ใน `src/App.tsx`
   - เพิ่ม `/account/orders` → redirect ไป `/my-account` พร้อม **ส่งต่อ query string เดิมทั้งหมด** (`?order=...`)
   - `/my-orders` → redirect ไป `/my-account` (ส่งต่อ query เช่น `?bucket=`) เพื่อให้เหลือหน้าเดียวจริง
   - `/my-orders/:id`, `/my-orders/:id/receipt` คงเดิม
5. ในแผงประวัติ: ถ้ามี `?order=<id>` ให้เลื่อน (scroll) ไปที่การ์ดออเดอร์นั้นและไฮไลต์ชั่วคราว ถ้าไม่พบก็แสดงรายการปกติเฉย ๆ (ไม่ error)
6. อัปเดตเทสต์ที่อ้าง route/ข้อความเดิม และเพิ่มเทสต์ใหม่: `/account/orders` และ `/my-orders` redirect ถูกที่ + query ไม่หาย, ลิงก์ที่ edge function ส่งยังตรงกับ route ที่มีจริง

## ไม่แตะ
- Edge functions / ข้อความ LINE / business logic ของออเดอร์ทั้งหมด
- หน้า `/account/orders/pending|history|status` ที่มีอยู่เดิม (คนละเส้นทาง ยังใช้ได้)

# แยกแดชบอร์ดแอดมิน ออกจาก FILM SHOP + จูนหน้าให้ตรงม็อกอัป

## สถานะปัจจุบัน (ตรวจแล้วจากโค้ด)
- `src/App.tsx` บรรทัด 328–331: `/admin`, `/admin/home`, `/admin/dashboard` ทั้งหมด **redirect ไป `/receipts/film`** → แอดมินกับ FILM SHOP จึงกลายเป็นหน้าเดียวกัน
- `src/lib/adminNav.ts`: `DASHBOARD_NAV` รายการ "หน้าหลัก" ก็ชี้ `/receipts/film`
- `src/components/layout/DashboardShell.tsx` (sidebar navy ของ NATTA GROUP) มีอยู่แต่ **ไม่มี route ไหนใช้แล้ว**
- แดชบอร์ดโทนม่วงตามม็อกอัปที่เพิ่งทำ อยู่ที่ `src/film-shop/components/dashboard/FilmShopDashboard.tsx` (อยู่ในฝั่ง FILM SHOP)

## สิ่งที่จะทำ

### 1) แยกสองหน้าออกจากกันจริง
- สร้าง `src/pages/admin/AdminDashboardHome.tsx` = **แดชบอร์ดแอดมิน (NATTA GROUP)** ครอบด้วย `DashboardShell` (sidebar navy + เมนูหลัก)
- เปลี่ยน route: `/admin`, `/admin/dashboard` → `/admin/home`; `/admin/home` render หน้าใหม่ (ไม่ redirect ไป `/receipts/film` อีก)
- `/receipts/film` = **FILM SHOP** คงเดิม ใช้ `FilmShopDashboard` + sidebar FILM SHOP ของตัวเอง
- ย้าย UI ที่ใช้ร่วมกัน (การ์ดโมดูล, Panel, Sparkline, สถานะ pill, skeleton/empty) ไป `src/components/dashboard/ng/` เพื่อให้สองหน้าหน้าตาเป็นชุดเดียวกันแต่ข้อมูล/ปลายทางแยกกัน

### 2) แก้เมนู/ลิงก์ให้ไม่ปนกัน
- `DASHBOARD_NAV`: "หน้าหลัก" → `/admin/home`, เพิ่มรายการ **"FILM SHOP"** → `/receipts/film`
- Sidebar FILM SHOP: เพิ่มปุ่ม **"กลับแดชบอร์ดแอดมิน"** → `/admin/home`
- ปุ่มโมดูลบนแดชบอร์ดแอดมินใช้ `MODULE_CARDS` (canonical routes เดิม) แทน `onPageChange` ภายใน FILM SHOP

### 3) ปุ่ม/ลิงก์ด่วนในทุกโมดูล (ทุกปุ่มมี action จริง)
| การ์ด | ลิงก์ด่วน → ปลายทาง |
|---|---|
| ออเดอร์วันนี้ | ดูออเดอร์วันนี้ → `/receipts/film?p=orders` · คิวงาน → `?p=group-queue` |
| งานล่าสุด | แถวคลิกได้ → เปิดคิวงาน · ดูทั้งหมด → `?p=group-queue` |
| สินค้าใกล้หมด (การ์ดใหม่) | รายการใกล้หมด → `/admin/products?status=low` · เติมสต๊อก → `/admin/product-stock` · จัดซื้อ → `/admin/purchases` |
| ลูกค้า | ลูกค้ายอดนิยม → `/admin/customers` · เปิดโปรไฟล์ลูกค้ารายคน |
| ประกาศ / แจ้งเตือน | ดูทั้งหมด → หน้าประกาศเดิม · คลิกรายการเปิดต้นทาง |
| ยอดขายวันนี้ | ดูรายงาน → `/admin/reports` · ออกเอกสาร → `/receipts` |
- ปุ่มไหนไม่มีปลายทางจริง = ไม่แสดง (ไม่มี placeholder)

### 4) จูนให้ตรงม็อกอัป 1:1
ตรวจและปรับตามสเปกเดียวกันทั้งสองหน้า:
- sidebar 250–272px navy `#12104F → #141667`, active = gradient ม่วง
- hero gradient `#3B1170 → #6D28D9 → #9333EA → #D9468D`, radius 16–18, padding 20–24
- หัวข้อการ์ด 14.5–15px/bold, ตัวเลขเมตริก 24–28px/extrabold tabular, label 12px `#5B6690`, หัวตาราง 11.5px `#8A93B2`
- การ์ด: bg ขาว, border `#E7EAF2`, radius 14–16, shadow เบา; canvas `#F7F8FA`
- pill สถานะใช้ชุดสีเดียว (violet/blue/orange/green/gray)
- ตรวจ layout จริงด้วย Playwright ที่ 1536 / 1280 / 768 / 390 แล้วปรับ gap/padding/ขนาดตัวอักษรให้เท่าม็อกอัป

### 5) ไม่แตะของต้องห้าม
เอกสาร 2 ร้าน (template/VAT/PDF/เลขที่), POS engine, stock movements, queue/run-work, group bot/LINE backend, auth/roles, DB schema — เปลี่ยนเฉพาะ presentation + routing/links

### 6) ตรวจสอบ
- typecheck + vite build
- แก้เทสต์ที่ผูกกับ route เดิม (`nav-refactor`, `nav-simplify`, `ops-menus-retired`, `film-shop-dashboard`) ให้สะท้อนการแยกหน้า
- เทสต์ใหม่: `/admin/home` ไม่ redirect, ลิงก์ด่วนทุกใบชี้ route ที่มีจริง, FILM SHOP กับแอดมินไม่ใช้หน้าเดียวกัน
- ไม่ publish/deploy

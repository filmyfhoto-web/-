# Reels แนะนำเว็บไซต์ (9:16) — เลื่อน ซูม โชว์ฟังก์ชัน

ทำคลิปแนะนำเว็บ NATTA GROUP แบบ Reels ที่ให้ "ความรู้สึกเหมือนคลิปแนวนอน" คือมีการเลื่อนหน้าเว็บ (scroll pan), ซูมเข้าจุดสำคัญ (Ken Burns / punch-in), และป้ายชี้ฟังก์ชัน — แต่จัดองค์ประกอบใหม่ให้เต็มจอ 1080×1920

## แนวคิดภาพ

- ถ่ายหน้าเว็บจริงด้วย Playwright 2 แบบ: เดสก์ท็อป (1440 กว้าง, full-page) สำหรับฉากเลื่อน/ซูมแบบคลิปแนวนอน และมือถือ (390×844) สำหรับฉากที่ต้องโชว์การใช้งานจริง
- ฉากเดสก์ท็อป: วางภาพเต็มความกว้างเฟรม แล้วเลื่อนขึ้น-ลง + ซูมช้า ๆ (ไม่กระตุก) ตัดคร็อปเป็น 9:16 โดยล็อคจุดสนใจไว้กลางเฟรม
- ฉากมือถือ: โชว์เครื่องโทรศัพท์กลางจอ + จุดแตะ (tap) ตามลำดับการใช้งาน
- ข้อความไทยสั้น 1 บรรทัดต่อฉาก ด้านล่าง อยู่ใน safe area (บน 190px / ล่าง 230px) ตามที่ตั้งไว้เดิม
- โทนเดิม: navy #0B1E32, ม่วง #7C3AED / #A855F7, พื้นขาวอุ่น + ดนตรีคลาสสิก (Canon in D) คลอเบา

## ลำดับฉาก (~40–45 วินาที)

1. Hook: โลโก้ NATTA GROUP + "งานพิมพ์ที่ใช่ บริการที่คุณไว้ใจ" (ซูมออกจากโลโก้)
2. หน้าแรก — เลื่อนลงยาวโชว์ hero → การ์ดคุณภาพ/รวดเร็ว/ปลอดภัย
3. เมนูหลัก — ซูมเข้าแถบเมนู ไฮไลต์ทีละรายการ
4. สั่งซื้อสินค้า — เลื่อนดูรายการสินค้า + ซูมเข้าราคาสินค้า
5. ตะกร้า / ขอราคา — โชว์ขั้นตอนบนมือถือพร้อมจุดแตะ
6. ใบเขียนเบิก — โชว์ Smart Import วางจาก Excel + คำนวณอัตโนมัติ (ป้าย "ไม่ตัดสต๊อก")
7. คำสั่งซื้อของฉัน / ติดตามงาน — ซูมเข้าสถานะ
8. ปิดท้าย: LINE + ที่อยู่เว็บ filmyynatta.com

## รายละเอียดเทคนิค

- ไฟล์ใหม่ `remotion/src/SiteReels.tsx` + คอมโพเนนต์ช่วย `PanZoomShot.tsx` (รับภาพ + จุดเริ่ม/จบของ scale & offset แล้ว interpolate ด้วย easing นุ่ม)
- ลงทะเบียน composition `site-reels` (1080×1920, 30fps) ใน `remotion/src/Root.tsx`
- ภาพหน้าจอใหม่เก็บที่ `remotion/public/images/site/` (สคริปต์ Playwright ชั่วคราวใน /tmp)
- เรนเดอร์ผ่าน `scripts/render-remotion.mjs` แล้วผสมเสียงด้วย ffmpeg → `/mnt/documents/natta-site-reels-9x16-th.mp4`
- ไม่แตะโค้ดแอป (auth, POS, สต๊อก, เอกสาร, คิว, บอท) — เพิ่มเฉพาะไฟล์ในโฟลเดอร์ remotion

# หน้าแรก: รูปร้านเล็กลง + แผงต้อนรับพอดีทุกจอ + รูปโปรไฟล์ LINE อัปเดตทันที

## 1. รูปหน้าร้านเล็กลง (ตามภาพอ้างอิง)
- ลดความสูงกรอบรูปหน้าร้าน: มือถือ ~11rem, แท็บเล็ต ~14rem, เดสก์ท็อป ~18rem (เดิม 16/19/26rem) โดยยังคูณกับสเกลที่ตั้งได้จากหลังบ้าน (`heroScaleOf`) เหมือนเดิม
- ปรับสัดส่วนคอลัมน์ hero เป็นข้อความกว้างขึ้นเล็กน้อย (`lg:grid-cols-[1.05fr_1fr]`) ให้หัวเรื่อง "งานพิมพ์ ที่ใช่ / บริการ ที่คุณไว้ใจ" เด่นตามภาพ
- ป้าย "เปิดบริการ จันทร์-ศุกร์…" วางทับมุมล่างของรูปแบบไม่ล้นกรอบ และซ่อนบนจอเล็กเหมือนเดิม
- การ์ดจุดเด่น 3 ใบ (คุณภาพดี / รวดเร็ว / ปลอดภัย) คงไว้ใต้ปุ่ม "ดูวิดีโอสอนใช้งาน"

## 2. แผงต้อนรับให้พอดีทุกขนาดจอ
- ให้แผงต้อนรับ (ยินดีต้อนรับ + รหัสลูกค้า + การ์ดทางลัด 3 ใบ + แถบสถานะออเดอร์) ใช้ความกว้างเต็มคอลัมน์ ไม่ผูกกับความสูงของรูปร้าน — รูปร้านเป็นบล็อกย่อยขนาดคงที่ในแผง
- กริดทางลัด: 1 คอลัมน์ (<640px) → 2 (sm) → 3 (lg); ข้อความยาวใช้ตัดบรรทัด/`truncate` กันล้น
- แถบสถานะ 4 ช่อง: มือถือเป็นกริด 2x2 ซ่อนลูกศร, ตั้งแต่ sm ขึ้นไปเรียงแนวนอนพร้อมลูกศร, ปุ่ม "ดูประวัติทั้งหมด" ลงบรรทัดใหม่เต็มความกว้างบนจอเล็ก
- ตรวจไม่ให้เนื้อหาซ้อนทับด้วย `min-w-0` / `overflow-hidden` ที่คอนเทนเนอร์ และลด negative margin ของแถบสถานะบนมือถือ

## 3. รูปโปรไฟล์ LINE ถูกต้องและอัปเดตทันทีหลังเชื่อมต่อ
- อวาตาร์ใช้ `pictureUrl` จาก `useLineBindingState` (ผ่าน `safePictureUrl` https เท่านั้น) ถ้าโหลดรูปไม่ได้ให้ตกไปที่อักษรย่อชื่อ
- อัปเดตทันที: หลังกลับจากการเชื่อม LINE ให้เรียก `refresh()` เมื่อแท็บกลับมา focus/visible (ฮุกมีอยู่แล้ว) และเพิ่มการ refresh ครั้งเดียวเมื่อสถานะเปลี่ยนจาก unlinked → linked เพื่อดึงชื่อ/รูปล่าสุด
- ถ้ายังไม่ผูก LINE: แสดงเฉพาะ "ยินดีต้อนรับ / คุณยังไม่ได้เป็นสมาชิกของร้าน" + ปุ่มเชื่อมต่อ LINE (คงพฤติกรรมเดิม)

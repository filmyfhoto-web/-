# บังคับผูก LINE + จัดหน้าให้พอดีทุกจอ + สแกนบาร์โค้ดด้วยกล้องในหน้า POS

## 1) ลูกค้าต้องผูก LINE ก่อนเข้าใช้งาน (ทั้งมือถือและ PC)

สถานะปัจจุบัน: ตัวกั้น `RequireLineLink` ปล่อยให้ผู้ที่ล็อกอินด้วยอีเมล/มีเซสชันแต่ยัง **ไม่ได้ผูก LINE** เข้าใช้งานได้ (สถานะ `verified_no_line`) ซึ่งขัดกับที่ต้องการ

จะเปลี่ยนเป็น:
- ยังไม่ผูก LINE = เข้าไม่ได้ทุกกรณี ระบบพาไปหน้าผูกบัญชี LINE พร้อมปุ่ม "เข้าสู่ระบบด้วย LINE" และจำหน้าปลายทางเดิมไว้ กลับมาหน้าเดิมหลังผูกเสร็จ
- ผูกแล้ว = เข้าได้ทันที ไม่ต้องผูกซ้ำ (ยังใช้แคชตรวจสิทธิ์เดิมเพื่อไม่ให้หน่วง)
- พนักงาน/แอดมิน ยังข้ามการผูกได้เหมือนเดิม
- กรณีเน็ตล่ม/LINE ล่มชั่วคราว: ถ้าเคยยืนยันสำเร็จในเซสชันนี้ยังใช้ต่อได้ ถ้าไม่เคย จะขึ้นหน้าลองใหม่ (ไม่ปล่อยผ่าน)
- ปิดช่องหลุด: ทุกเส้นทางฝั่งลูกค้า (`/shop`, `/shop/pos`, `/cart`, `/my-orders`, `/my-account`, ใบเสร็จ, `/school/:token`, ลิงก์ย่อ `/s`) ต้องผ่านตัวกั้นเดียวกัน และหน้าแรกของโดเมนลูกค้าจะพาไปผูก LINE ถ้ายังไม่ผูก

## 2) จัดหน้าเว็บแอปให้พอดีทุกอุปกรณ์ (PC / แท็บเล็ต / iPad / มือถือ)

- ตารางที่ล้นจอ (ตะกร้า POS, รายการสินค้า, รายงาน, เอกสาร): บนจอเล็กเปลี่ยนเป็นการ์ดรายการแทนตาราง บนจอกลางให้เลื่อนแนวนอนเฉพาะในกรอบตาราง ไม่ทำให้ทั้งหน้าเลื่อนหลุด
- แถบหัว POS และแถวปุ่มสี: เลื่อนแนวนอนได้ในกรอบตัวเอง ไม่ดันความกว้างหน้าจอ
- แผง Numpad/สรุปยอดด้านขวา: บนจอต่ำกว่าแท็บเล็ตย้ายไปเป็นแถบด้านล่างแบบติดขอบ กดง่ายด้วยนิ้ว
- รองรับ safe-area ของ iPhone/iPad และความสูงจอจริง (dvh) กันแถบล่างโดนบัง
- ตรวจทุกหน้าหลักที่ 390 / 768 / 1024 / 1280 px ให้ไม่มีการเลื่อนแนวนอนของทั้งหน้า

## 3) สแกนบาร์โค้ดด้วยกล้องในหน้า POS

- เพิ่มปุ่มกล้องในช่องค้นหาของ `/pos/register` (และหน้า POS ที่ใช้ช่องค้นหาเดียวกัน)
- ใช้ตัวสแกนที่มีอยู่แล้วในระบบ (ZXing ผ่าน `PhotoBarcodeDialog`) — สแกนสด ถ่ายรูป หรือเลือกไฟล์จากแกลเลอรี ทำงานในเครื่อง ไม่ใช้เครดิต AI
- สแกนได้ผล = เติมรหัสลงช่องค้นหาและเพิ่มสินค้าเข้าตะกร้าอัตโนมัติเหมือนยิงด้วยเครื่องสแกน
- ถ้าไม่พบสินค้า แจ้งเตือนพร้อมเปิดช่องค้นหาด้วยชื่อแทน
- เครื่องสแกนแบบ USB/บลูทูธเดิมยังใช้ได้ตามปกติ

## รายละเอียดทางเทคนิค

- `src/components/RequireLineLink.tsx`: ตัดสถานะ `verified_no_line` ออก ให้ `bound !== true` ไปที่ `needs_login` เสมอ; คง staff bypass และแคช 60 วินาที
- `src/App.tsx`: ครอบเส้นทางฝั่งลูกค้าที่ยังไม่ได้ครอบด้วย `RequireLineLink`
- POS: เพิ่มปุ่มกล้อง + state เปิด `PhotoBarcodeDialog` ใน `src/pages/pos/PosRegister.tsx` ส่งผลลัพธ์เข้า `handleCode()` เดิม
- Responsive: ปรับเฉพาะชั้นการแสดงผล (Tailwind/CSS) ในตาราง POS, แถบปุ่ม, แผงขวา และ shell ของหน้า admin/shop
- ทดสอบ: เพิ่ม Playwright ตรวจ (ก) ผู้ใช้ยังไม่ผูก LINE ถูกพาไปหน้าผูกทุกเส้นทางลูกค้า (ข) ไม่มี horizontal overflow ที่ 390/768/1024/1280 (ค) ปุ่มกล้องเปิด dialog และผลสแกนเพิ่มสินค้าเข้าตะกร้า

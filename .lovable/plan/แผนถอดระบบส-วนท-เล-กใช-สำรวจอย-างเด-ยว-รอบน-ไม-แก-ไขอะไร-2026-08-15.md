## 5) “ขายและเอกสาร” — และคำตอบเรื่องการทับกับ /receipts/*

กลุ่มเมนูนี้ถูกยุบไปแล้ว เมนูที่เคยอยู่ในกลุ่มแยกเป็น 2 ฝั่งชัดเจน:

| เมนูเดิม | ปลายทางข้อมูล | ทับ /receipts/* ไหม | ทำอะไร |
|---|---|---|---|
| เอกสารที่บันทึก (`documents`) | `documents` / `document_items` ของ 2 ร้าน | **ทับ — คือ /receipts เอง** | เก็บไว้ |
| ใบเสร็จ (`receipts`) | เหมือนข้างบน | **ทับ** | เก็บไว้ |
| POS (`pos`), สต๊อก (`stock`) | POS / สต๊อกกลาง | ไม่ทับ และห้ามแตะ | เก็บไว้ |
| ศูนย์ออเดอร์ (`orders`, `intake`) | `film_orders` `film_order_items` `film_order_events` | **ไม่ทับ** | ถอด (ข้อ 6) |
| ออกเอกสารด้วยคำสั่ง (`doc-command`) | `film_invoices` + edge function `doc-command` | **ไม่ทับ** | ถอด |
| ใบสั่งจ้าง (`invoices` / `job-orders`) | `film_invoices` | **ไม่ทับ** | ถอด (ผูกกับคิวงาน) |

สรุป: เอกสาร 2 ร้านที่ `/receipts/*` ใช้ตาราง `documents` / `document_items` ต่อร้าน
ส่วนที่จะถอดใช้ `film_orders` / `film_invoices` คนละชุดกัน จึงถอดได้โดยไม่กระทบเอกสารสองร้าน

## ลำดับงานที่เสนอ (ยังไม่ทำจนกว่าจะอนุมัติ)

- เฟส 2A — ตัดลิงก์ค้าง: ปิดลิงก์ที่ยังชี้เข้าหน้าเลิกใช้ (`AdminActivityFeed`, `LiveDetailPanel`,
  `AdminNotificationCenter`, `Tools.tsx`, `StaffHome`, `WorkspaceLinksCard`) และให้ route ข้อ 2–3
  ฝั่งแอดมินรีไดเรกต์ไป `/receipts/film` ผ่านสวิตช์เดิม — ยังไม่ลบไฟล์
- เฟส 2B — ลบไฟล์: ลบตามรายการข้อ 1–6 ทีละกลุ่ม พร้อมรัน typecheck + ชุดทดสอบทุกกลุ่ม
- เฟส 3 — ล็อกฝั่งหลังบ้าน: `REVOKE` สิทธิ์ `anon`/`authenticated` บนตารางที่เลิกใช้
  (`film_orders*`, `film_job_requests`, `film_conversations`, ฯลฯ) และปิด edge function
  ที่รับคำสั่งจากลูกค้า — **ไม่มี DROP TABLE / DELETE ข้อมูลใด ๆ**

## แผน rollback (ไม่ลบข้อมูล production)

1. ชั้นที่ 1 — สลับ `src/lib/legacyUi.ts` กลับเป็น `true` เมนูและ route กลับมาทันที (ใช้ได้จนจบเฟส 2A)
2. ชั้นที่ 2 — เฟส 2B ลบไฟล์เป็นคอมมิตแยกต่อกลุ่ม ย้อนได้ด้วยการ revert คอมมิตนั้น
3. ชั้นที่ 3 — เฟส 3 ใช้เฉพาะ `REVOKE` และเปลี่ยนสถานะ ย้อนด้วย `GRANT` กลับ
   ข้อมูลยังอยู่ครบ ไม่มี DROP/DELETE/TRUNCATE ในทุกเฟส
4. ก่อนเฟส 3 บันทึกรายการสิทธิ์เดิมของทุกตารางที่จะแตะ เพื่อคืนค่าได้ตรงเดิม

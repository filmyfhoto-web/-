## 2. แผงต้อนรับลูกค้าบนหน้าแรก (ตามภาพอ้างอิง)

เพิ่มบล็อกใหม่ในฮีโร่ของ `Welcome` ฝั่งขวา (แทนที่/ครอบรูปฮีโร่เดิม) เห็นเฉพาะผู้ที่ล็อกอินแล้ว:

```text
[ ยินดีต้อนรับ / ชื่อลูกค้า ]        [ รูปหน้าร้าน (hero image เดิม) ]
[ รหัสลูกค้า CUS-00127  (ปุ่มคัดลอก) ]
[ ● เชื่อมต่อ LINE แล้ว — ชื่อโปรไฟล์ LINE ]
[ ใบเขียนเบิก ] [ สั่งซื้อสินค้า ] [ นำเข้า Excel ]   ← การ์ด 3 ใบ มีลูกศร
```

- ชื่อ/รหัสลูกค้า: อ่านจากโปรไฟล์ลูกค้าเดิม (`customer_code` ที่ทำไว้ใน Customer 360) ปุ่มคัดลอกรหัส
- สถานะ LINE: ใช้ตัวช่วยเช็คการผูกบัญชีที่มีอยู่ (`lineBinding`) — ถ้ายังไม่ผูก แสดงปุ่ม "เชื่อมต่อ LINE"
- การ์ด 3 ใบลิงก์ไปเส้นทางจริง: `/school-requisition`, ปุ่มสั่งซื้อเดิมของหน้าแรก, `/account/excel`
- ผู้ที่ยังไม่ล็อกอิน: หน้าแรกเหมือนเดิมทุกประการ (ฮีโร่ + ปุ่ม CTA เดิม)

## 3. แถบ "ประวัติและสถานะคำสั่งซื้อ"

แถบเดียวใต้ฮีโร่ (เฉพาะผู้ล็อกอิน) นับจริงจากข้อมูลลูกค้า:

- 4 ช่อง: รอดำเนินการ / เสนอราคาแล้ว / จัดส่งแล้ว / เสร็จสิ้น พร้อมจำนวนรายการ
- แต่ละช่องกดแล้วไปหน้ารายการที่กรองสถานะนั้น (ใช้ `BUCKET_ROUTES` / `/account/orders/*` เดิม)
- ปุ่ม "ดูประวัติทั้งหมด" → `/account/history` (ประวัติรวมทุกช่องทาง)
- ระหว่างโหลดใช้ skeleton, ถ้ายังไม่มีข้อมูลแสดงเลข 0 ไม่ซ่อนแถบ

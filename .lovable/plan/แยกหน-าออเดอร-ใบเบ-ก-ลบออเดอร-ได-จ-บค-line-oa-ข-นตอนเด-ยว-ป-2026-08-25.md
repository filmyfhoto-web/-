# แยกหน้าออเดอร์/ใบเบิก · ลบออเดอร์ได้ · จับคู่ LINE OA ขั้นตอนเดียว · ปิดแจ้งเตือนร้านปริ้นงาน

## 1. แยก "ออเดอร์สั่งของ" กับ "ใบเขียนเบิก" เป็นคนละหน้า

- `/admin/customer-purchase-orders` = ออเดอร์สั่งของอย่างเดียว (ตัดแถบสลับ 2 แท็บด้านบนออก)
- `/admin/school-requisitions` = หน้าใบเขียนเบิกจริง (ไม่ redirect ไปหน้าออเดอร์อีก)
- ลิงก์เก่า `?tab=requisitions` (จาก LINE / แจ้งเตือน) ให้เด้งไปหน้าใบเขียนเบิกใหม่โดยคงพารามิเตอร์ `?id=` ไว้ — ลิงก์เดิมไม่พัง
- ทั้งสองหน้ามีปุ่ม "กลับหน้าหลัก" และหัวข้อของตัวเอง; แท็บใน `/admin/customer-hub` ชี้ปลายทางใหม่ให้ถูกหน้า

## 2. ดู / ลบออเดอร์ได้

ในตารางออเดอร์ (ทั้งหน้าออเดอร์และแท็บออเดอร์ในศูนย์รวมงาน) เพิ่ม 2 ปุ่มต่อแถว:

- **ดู** — เปิดรายละเอียดออเดอร์ (แผงขวาเดิม)
- **ลบ** — ลบถาวรออกจากฐานข้อมูล พร้อมกล่องยืนยันที่ระบุเลขที่บิลและชื่อลูกค้า ลบแล้วรีเฟรชรายการทันทีและขึ้นข้อความยืนยัน

สิทธิ์ลบมีอยู่แล้วสำหรับพนักงาน (นโยบายฐานข้อมูลเดิมครอบคลุมการลบ) — ไม่ต้องเพิ่มสิทธิ์ใหม่

## 3. เชื่อมลูกค้ากับ LINE OA — อ่านเฉพาะร้านนัฐภรณ์ เชียงกลาง + ขั้นตอนเดียว

- รายชื่อเพื่อน LINE จะกรองเฉพาะเพื่อนของ OA ร้านนัฐภรณ์ เชียงกลาง (รหัสร้านหลัก) — ไม่ปนเพื่อนของร้านที่ 2 (ปริ้นงาน)
- ยุบแผง 3 ขั้นตอนเป็นแผงเดียว: ช่องค้นหาชื่อลูกค้าในระบบร้าน → เลือกลูกค้า → ช่องค้นหาเพื่อน LINE → กด "เพิ่ม/จับคู่ทันที" ในคลิกเดียว พร้อมแสดงรูปโปรไฟล์และ LINE ID ที่กำลังจะผูก
- จับคู่เสร็จ สถานะฝั่งซ้ายเปลี่ยนเป็นเขียวทันทีเหมือนเดิม (ใช้ฟังก์ชันจับคู่เดิม ไม่เปลี่ยน logic)

## 4. ปิดแจ้งเตือนของร้านนัฐภรณ์ การพิมพ์ (ปริ้นงาน)

- หยุดสร้างแจ้งเตือนพนักงานชนิด "สถานะเอกสาร ... เปลี่ยนเป็น issued" (`doc_status_change`) — ปรับทริกเกอร์เอกสารให้ไม่ยิงแจ้งเตือนรวมเข้าศูนย์แจ้งเตือนอีก ส่วนบันทึกกิจกรรมและแจ้งเตือนถึงลูกค้า/ผู้รับผิดชอบยังทำงานเหมือนเดิม
- ลบแจ้งเตือนพนักงานชนิดนี้ที่ค้างอยู่ (ประมาณ 1,492 รายการ) ออกจากฐานข้อมูล — หลังลบ ตัวเลข "ยังไม่ได้อ่าน" จะเหลือเฉพาะออเดอร์/ใบเบิก/แชท LINE จริง
- เอาการยิงแจ้งเตือนศูนย์รวมออกจากขั้นตอนออกเลขเอกสารฝั่ง Film Shop ด้วย (แจ้งเข้ากลุ่ม LINE ยังคงเดิม)

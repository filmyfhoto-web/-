# ปุ่มปรับเลย์เอาต์เอง + ลบป้ายเวอร์ชัน "ลูกค้า v1.2.0"

## 1. ลบป้ายเวอร์ชันมุมจอ
ป้าย "ลูกค้า v1.2.0" ที่ลอยมุมขวาล่างมาจากปุ่มใน `src/components/AppUpdateGate.tsx`
(`data-testid="global-version-badge"`) แสดงกับทุกบทบาท (ลูกค้า/พนักงาน/แอดมิน)

- ซ่อนปุ่มและกล่องข้อมูลเวอร์ชันนี้ออกจากทุกหน้า
- **คงระบบอัปเดตอัตโนมัติเดิมไว้ครบ** (ตรวจเวอร์ชันใหม่ + รีเฟรชตอนหน้าจอว่าง) แค่ไม่มี UI
- ข้อมูลเวอร์ชันยังดูได้ที่หน้า `/diagnostics` และการ์ดข้อมูลระบบในแอดมินเหมือนเดิม
- ปรับเทสต์ที่อ้างถึงป้ายนี้ (`global-update-gate`, `build-stamp-and-nav`, `pos-version-debug` เท่าที่เกี่ยวข้อง) ให้ยืนยันว่า "ต้องไม่มีป้ายนี้แล้ว"

## 2. ปุ่มปรับเลย์เอาต์ (ลอยมุมจอ ใช้ได้ทุกหน้า)
ปุ่มกลมเล็กลอยมุมขวาล่าง (ที่เดิมของป้ายเวอร์ชัน) กดแล้วเปิดแผงปรับหน้าจอ:

- **ขนาดตัวอักษร** 80–150% (สไลเดอร์ + ปุ่ม A- / A+)
- **ความกว้างเนื้อหา** แคบ / ปกติ / เต็มจอ
- **ความโปร่ง (ระยะห่าง)** แน่น / ปกติ / โปร่ง
- **ย้ายบล็อกเอง**: โหมด "จัดวาง" ลากสลับลำดับการ์ด/แผงบนหน้าที่รองรับ
  (เริ่มที่หน้าแรก/แผงต้อนรับ และแดชบอร์ดหลังร้าน) ปิดโหมดแล้วกลับมาใช้งานปกติ
- **แยกค่าต่อหน้า**: จำค่าแยกตามหน้า (path) + ปุ่ม "ใช้ค่านี้กับทุกหน้า" และ "รีเซ็ต"
- บันทึกเฉพาะอุปกรณ์นี้ (localStorage) ไม่กระทบผู้ใช้คนอื่น และ **ไม่มีผลกับการพิมพ์เอกสาร**

## รายละเอียดทางเทคนิค
- ขยาย `src/lib/displayPref.ts` เป็น `layoutPref` เก็บ `{ fontScale, width, density, order }`
  ต่อ path + ค่า global fallback อ่าน/เขียนผ่าน localStorage
- ใส่ค่าเป็น CSS variables บน `<html>`/คอนเทนเนอร์หน้า (`--ui-font-scale`, `--ui-max-w`, `--ui-gap`)
  แล้วให้ token ใน `index.css` ใช้ค่านี้ — ไม่แก้ component ทีละตัว ไม่แตะ business logic
- คอมโพเนนต์ใหม่ `src/components/common/LayoutTuner.tsx` (ปุ่มลอย + แผงตั้งค่า)
  เรนเดอร์ที่ระดับ App เดียวกับ `AppUpdateGate` ยกเว้นหน้าพิมพ์/POS register ที่มีแถบของตัวเอง
- โหมดจัดวาง: wrapper `SortableStack` เก็บลำดับ id ของบล็อกไว้ใน pref แล้วเรียงตอน render
  หน้าไหนยังไม่ได้ห่อ ก็แสดงเฉพาะปรับขนาด/ความกว้าง
- `@media print` ตรึงค่าเป็นค่ามาตรฐานทั้งหมด
- เพิ่มเทสต์: ค่า pref อ่าน/เขียนต่อ path, การรีเซ็ต, สลับลำดับบล็อก, และป้ายเวอร์ชันหายไปแล้ว

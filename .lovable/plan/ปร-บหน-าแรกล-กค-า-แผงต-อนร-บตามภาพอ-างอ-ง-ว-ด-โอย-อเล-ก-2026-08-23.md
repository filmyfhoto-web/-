# ปรับหน้าแรกลูกค้า: แผงต้อนรับตามภาพอ้างอิง + วิดีโอย่อเล็ก

## 1. เอาบล็อกวิดีโอใหญ่เดิมออก
- ลบส่วน "ดูคลิปสั้น แล้วสั่งซื้อเองได้เลย" (เครื่องเล่นใหญ่ + การ์ด "สั่งซื้อสินค้ากับร้าน" ด้านขวา) ออกจากหน้าแรก
- ปุ่มในการ์ดขวา (ดูสินค้า/คำสั่งซื้อของฉัน/ใบเขียนเบิก) ไม่หายจากระบบ เพราะมีทางลัดเดิมอยู่ในแผงต้อนรับและเมนูบัญชีแล้ว

## 2. วิดีโอสอนใช้งานแบบย่อ (hover แล้วขยาย)
- แทนที่ด้วยแถบวิดีโอขนาดเล็ก (thumbnail ~240px) วางเรียงแนวนอน 1–3 คลิป
- เอาเมาส์ชี้ (hover) → การ์ดขยายใหญ่ขึ้นลื่น ๆ และเริ่มเล่นตัวอย่างแบบไม่มีเสียง; เอาเมาส์ออก → ย่อกลับและหยุด
- คลิก/แตะ → เปิดโมดัลเล่นเต็มจอพร้อมซับไทย (บนมือถือใช้แตะแทน hover)

## 3. แผงต้อนรับลูกค้า ให้ตรงภาพอ้างอิงและพอดีทุกจอ
- ยังไม่ได้เชื่อม LINE: แสดงเฉพาะ "ยินดีต้อนรับ / คุณยังไม่ได้เป็นสมาชิกของร้าน" + ปุ่ม "เชื่อมต่อ LINE เพื่อรับแจ้งเตือนสถานะงาน" (ซ่อนรหัสลูกค้าและการ์ดทางลัด)
- เชื่อม LINE แล้ว: ใช้รูปโปรไฟล์ LINE จริงของลูกค้าเป็นอวาตาร์ (ถ้าไม่มีรูป ใช้ตัวอักษรแรกของชื่อ) พร้อมชื่อ, รหัสลูกค้า + ปุ่มคัดลอก, สถานะ "เชื่อมต่อ LINE แล้ว"
- การ์ดทางลัด 3 ใบ (ใบเขียนเบิก / สั่งซื้อสินค้า / นำเข้า Excel) จัดกริดยืดหยุ่น 1→2→3 คอลัมน์ ไม่ล้นจอทุกขนาด

## 4. แถบประวัติและสถานะคำสั่งซื้อ (ตามภาพที่ 2)
- ย้ายมาไว้ "ใต้" การ์ด 3 ใบ ในแผงต้อนรับ (เห็นเฉพาะลูกค้าที่เชื่อม LINE/ล็อกอินแล้ว)
- รูปแบบตามภาพ: หัวเรื่อง "ประวัติและสถานะคำสั่งซื้อ" ซ้ายสุด → ชิป 4 ช่อง (รอดำเนินการ / เสนอราคาแล้ว / จัดส่งแล้ว / เสร็จสิ้น) มีไอคอน ตัวเลข และคำว่า "รายการ" คั่นด้วยลูกศร → ปุ่ม "ดูประวัติทั้งหมด" ขวาสุด
- โทนสีชิปตามภาพ (ส้มอ่อน/ม่วงอ่อน/เขียวอ่อน/เทาอ่อน) โดยเพิ่มเป็น design token ไม่ hardcode
- จอเล็ก: เลื่อนแนวนอนได้หรือพับเป็นกริด 2x2 ลูกศรซ่อนอัตโนมัติ

## 5. ไอคอนให้ครบ
- เติมไอคอน lucide ให้ทุกช่องสถานะ ทุกการ์ดทางลัด ปุ่มคัดลอก ปุ่มเชื่อม LINE และปุ่มดูประวัติทั้งหมด (ตอนนี้บางจุดยังว่าง/ไม่ตรงความหมาย)

## C) จุดกำกวมที่ต้องให้เจ้าของยืนยันก่อนลงมือ

1. **“ขายและเอกสาร” ไม่ใช่ /receipts/\*** — เป็นแค่ชื่อกลุ่มเมนูใน Sidebar ของหน้าแอดมินหลัก (`/receipts/film`) ที่รวม 5 เมนู แต่ 2 ใน 5 คือ “เอกสารที่บันทึก” และ “สินค้า/สต๊อก” ซึ่งอยู่ในรายการห้ามแตะ
   → ข้อเสนอ: **ลบเฉพาะชื่อกลุ่ม + เมนู `orders` และ `doc-command`** แล้วย้าย `documents`, `stock`, `calculator` ไปกลุ่มอื่น ไม่ลบทิ้ง
2. **“ออเดอร์ออกเอกสาร”** — ในระบบไม่มีเมนูชื่อนี้ตรงตัว ผู้สมัครมี 3 ตัว: (ก) page `orders` “ศูนย์ออเดอร์” ใน film-shop, (ข) `doc-command` “ออกเอกสารด้วยคำสั่ง”, (ค) `/admin/customer-purchase-orders` “ออเดอร์ลูกค้า → ออกเอกสารจริง”
   → ต้องเลือกก่อน เพราะ (ค) เชื่อมกับ `/po/:token` ที่ส่งลูกค้าทาง LINE
3. `/receipts/*` **ไม่ถูกแตะ** ในทุกเฟสของแผนนี้ — ยืนยันชัดเจน
4. หลังลบหน้าลูกค้า ออเดอร์จาก MyShop จะเข้าที่ไหน? ปัจจุบันเข้า `orders` และดูได้ที่ `/admin/order-alerts` ซึ่งอยู่ในรายการ “ศูนย์แจ้งเตือน” ที่จะลบ → ต้องคงหน้าอ่านออเดอร์ MyShop ไว้อย่างน้อย 1 หน้า

## D) แผนแบ่งเฟส (rollback ได้ทุกเฟส)

**เฟส 0 — เตรียม (ไม่แตะโค้ด)**
- จดรายการ route ปัจจุบันจาก `/diagnostics/routes` เป็น baseline
- สร้าง feature flag `legacy_customer_ui` เพื่อปิด/เปิดกลับได้ทันที

**เฟส 1 — ซ่อน ไม่ลบ (rollback = สลับ flag)**
- ปิดเมนู/ลิงก์ของ Inbox, ศูนย์แจ้งเตือน, คิวงาน, กลุ่ม “ขายและเอกสาร” ออกจาก Sidebar/MobileNav
- เปลี่ยน route ลูกค้าทั้งหมดเป็น redirect ไปหน้าแจ้ง “ย้ายไป LINE MyShop” (ยังไม่ลบไฟล์)
- วัดผลความเร็ว bundle ก่อน/หลัง

**เฟส 2 — ถอดโค้ดออกจริง (rollback = revert commit)**
- ลบ route + ไฟล์หน้าจอ + component ที่ไม่มีใครอ้างถึงแล้ว ตามรายการ A1-A6 ที่ยืนยันในข้อ C
- ตัด provider ที่ไม่ใช้ (`CartProvider`, `GuestProvider`) ออกจาก `App.tsx`
- คง redirect ของ URL เก่าไว้กัน 404

**เฟส 3 — quarantine backend (ยังไม่ DROP)**
- ตัดสาขา NATTA.Q/inbox ออกจาก `line-webhook`, ปิด cron ของ `film-queue-automation`
- ตาราง queue/inbox: REVOKE สิทธิ์จาก `anon`/`authenticated` และเปลี่ยนชื่อ schema เป็น `deprecated_*` (ยังเก็บข้อมูลครบ)
- ห้าม DROP/DELETE — รอ 30 วัน แล้วค่อยเสนอรอบต่อไป

### รายการทดสอบ

**ก่อนทำ (baseline)**
1. ล็อกอิน staff / admin / owner ผ่านทั้ง 3 ประตู
2. เปิด PWA จากไอคอนหน้าจอ → ต้องเข้า `/receipts/film`
3. ออกใบเสนอราคา → ใบส่งของ → ใบเสร็จ + พิมพ์ PDF ครบ 2 ร้าน
4. POS ขาย 1 บิล → สต๊อกลด → `stock_movements` มีแถวใหม่
5. ซิงก์สต๊อกขึ้น MyShop สำเร็จ 1 รายการ
6. รับออเดอร์จาก MyShop → เห็นในระบบ

**หลังแต่ละเฟส** — ทำซ้ำ 1-6 ทั้งหมด บวก
7. เปิด URL ลูกค้าเก่าทุกตัว → ต้องได้หน้าแจ้งย้าย ไม่ใช่หน้าขาว/404
8. `/diagnostics/routes` ไม่มี route เสีย
9. console ไม่มี error ใหม่, ตรวจ bundle size ลดลงจริง

# หน้าแรกจบใน 1 หน้าจอ + สถานะโหลดรูป LINE + ล็อกการสั่งซื้อเมื่อยังไม่เชื่อม LINE

## 1. รูปโปรไฟล์ LINE: Skeleton + ปุ่มรีเฟรช
- ระหว่างตรวจสถานะ (`status === "loading"`) หรือรูปยังโหลดไม่เสร็จ ให้แสดงวงกลม skeleton เต้นจาง ๆ แทนอวาตาร์ พร้อมแถบ skeleton ของชื่อ/รหัสลูกค้า (ไม่ค้างเป็นช่องว่างเปล่า)
- โหลดรูปไม่สำเร็จ (`onError`) หรือไม่มีรูป → แสดงอักษรย่อชื่อ + ข้อความเล็ก "โหลดรูปไม่สำเร็จ"
- เพิ่มปุ่มไอคอนรีเฟรชข้าง ๆ อวาตาร์ (aria-label "รีเฟรชรูปโปรไฟล์ LINE") กด = เรียก `refresh(true)` ของ `useLineBindingState` + ล้างสถานะ error แล้วลองโหลดรูปใหม่ (bust cache ด้วย query param เวลา) ระหว่างกดปุ่มหมุน spinner และปิดปุ่มกันกดรัว
- ไม่แตะ business logic ของการผูก LINE — ใช้ hook เดิมล้วน

## 2. เพิ่ม 2 หัวข้อจากภาพอ้างอิง (ใช้ระบบเดิม)
- แถวการ์ดทางลัด 3 ใบ (ใบเขียนเบิก / สั่งซื้อสินค้า / นำเข้า Excel) และแถบ "ประวัติและสถานะคำสั่งซื้อ" (รอดำเนินการ / เสนอราคาแล้ว / จัดส่งแล้ว / เสร็จสิ้น + ปุ่มดูประวัติทั้งหมด) แสดงบนหน้าแรก **ทั้งกรณีเชื่อม LINE แล้วและยังไม่เชื่อม** (เดิมกรณียังไม่เชื่อมจะไม่แสดง)
- กรณียังไม่เชื่อม LINE: แถบสถานะแสดงตัวเลข 0 พร้อมข้อความ "เชื่อม LINE เพื่อดูประวัติของคุณ" — ยังกดเข้าไปหน้าประวัติได้ แต่จะว่าง

## 3. สิทธิ์เมื่อยังไม่เชื่อม LINE
- ดูสินค้า (`/shop`) และเปิดหน้าใบเขียนเบิก (`/school-requisition`) ได้ตามเดิม
- แต่ปุ่มที่ "ยืนยันสั่งซื้อ / ส่งรายการให้ร้าน" จะเปลี่ยนเป็นปุ่มเชื่อมต่อ LINE พร้อมข้อความอธิบาย (ใช้ `useLineBindingState` เป็นตัวตัดสินฝั่งหน้าจอ; ฝั่งเซิร์ฟเวอร์ยังบังคับเหมือนเดิม ไม่แก้)
- หน้าประวัติ/ประวัติรวม: เข้าได้ แต่ถ้ายังไม่เชื่อมจะแสดง empty state + ปุ่มเชื่อม LINE แทนรายการ

## 4. จัดหน้าแรกให้พอดี 1 หน้าจอ ไม่ต้องเลื่อน
- ให้ส่วน hero + แผงต้อนรับ + ทางลัด + แถบสถานะ อยู่ในคอนเทนเนอร์สูง `100dvh` (หัก header) แบบ `grid` ที่บีบ/ขยายตามความสูงจริง
- ปรับสเกลตามช่วงจอ: มือถือ (รูปร้านเล็กลง/ซ่อนคำโปรย, การ์ดทางลัดเป็นแถวเตี้ย, แถบสถานะ 2x2 ตัวเลขย่อ), แท็บเล็ต/ไอแพด (2 คอลัมน์), เดสก์ท็อป (ตามภาพอ้างอิง)
- ใช้ระยะห่าง/ฟอนต์แบบ clamp() เพื่อไม่ให้ล้นในจอเตี้ย และ `min-h-0` + `overflow-hidden` กันเนื้อหาดันจนเกิด scroll
- ถ้าจอเตี้ยมาก (< ~620px สูง) ยอมให้เลื่อนได้ตามปกติเพื่อไม่ให้ตัวอักษรเล็กจนอ่านไม่ออก

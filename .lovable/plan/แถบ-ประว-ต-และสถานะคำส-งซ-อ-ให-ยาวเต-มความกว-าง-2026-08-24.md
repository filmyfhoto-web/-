# แถบ "ประวัติและสถานะคำสั่งซื้อ" ให้ยาวเต็มความกว้าง

ตามภาพอ้างอิง: แถบประวัติต้องหลุดออกจากกล่องแผงต้อนรับ แล้วทอดยาวเต็มความกว้างของหน้า (กว้างกว่ากล่องด้านบน) ทั้งกรณีเชื่อม LINE แล้วและยังไม่เชื่อม

## สิ่งที่จะได้
- แถบประวัติย้ายออกมาอยู่ "นอก" การ์ดแผงต้อนรับ เป็นแถวเต็มความกว้างของหน้าแรก
- หัวข้อ "ประวัติและสถานะคำสั่งซื้อ" + บรรทัด "เชื่อม LINE เพื่อดูประวัติของคุณ" อยู่ชิดซ้ายของแถบยาว
- 5 ช่อง (รอดำเนินการ / เอกสารออกแล้ว / ได้รับเอกสารแล้ว / ประวัติสั่งซื้อ / ดูประวัติทั้งหมด) กระจายเต็มความกว้าง ยืดตามจอ ไม่มีขอบมน
- มือถือยังเลื่อนแนวนอนแบบ snap ได้เหมือนเดิม
- หน้า "ประวัติทั้งหมด" ที่ใช้แถบเดียวกันยังทำงาน (sticky) เหมือนเดิม

## รายละเอียดเชิงเทคนิค
- `src/components/home/CustomerHomePanel.tsx`: ถอด `<OrderStatusStrip />` ออกจากภายในการ์ดทั้งสองสาขา (linked / not linked) แล้วห่อ return ด้วย fragment ให้แถบเป็นพี่น้องของการ์ด (`<>...การ์ด...<OrderStatusStrip/></>`) — ไม่แตะ logic โหลดข้อมูล/LINE
- `src/components/home/OrderStatusStrip.tsx`: ปรับความกว้างให้เต็ม (`w-full`), ตัด `min-w-[560px]` เป็นบังคับเฉพาะจอเล็ก (`sm:min-w-0`) เพื่อให้เดสก์ท็อปยืดเต็ม, คงมุมเหลี่ยม/เส้นแบ่ง/`data-testid` เดิมทั้งหมด
- หากหน้าแรกครอบแผงไว้ในคอนเทนเนอร์ที่แคบกว่า `max-w-7xl` จะย้ายจุดวางแถบไปอยู่ระดับ section เดียวกับ hero เพื่อให้ยาวจริง
- ไม่แก้ `countBuckets`, edge function `my-line-orders`, หรือเส้นทางลิงก์
- รันชุดเทสต์ที่อ้างถึงแถบนี้ (`customer-final-polish`, `account-routes`) ยืนยันผ่าน

# ข้อความต้อนรับหลังเพิ่มเพื่อน LINE พร้อมปุ่มลัด

## ปัญหา
ตอนนี้เมื่อลูกค้ากดเพิ่มเพื่อน (follow event) ระบบ **ไม่ตอบอะไรเลย** — โค้ดใน webhook มีคอมเมนต์ว่า "ไม่ส่งข้อความแนะนำผูกบัญชีอัตโนมัติแล้ว" และทำแค่ส่งสัญญาณ realtime กลับเว็บ ลูกค้าจึงค้างอยู่ในหน้าแชทโดยไม่มีทางไปต่อ

## สิ่งที่จะทำ
ส่ง **ข้อความต้อนรับ 1 ข้อความ (Flex การ์ด)** ทันทีหลัง follow โดยตอบผ่าน replyToken ของ event นั้น การ์ดมี:

- หัวข้อ: ขอบคุณที่เพิ่มเพื่อนกับร้าน + บอกว่าเลือกเมนูด้านล่างเพื่อเริ่มได้เลย
- ปุ่ม "สั่งสินค้า" → เปิด `/shop`
- ปุ่ม "ทำใบเบิก" → เปิด `/school-requisition`
- แนบ quick reply ปุ่มเดียวกันไว้ด้วย เพื่อให้กดต่อได้แม้เลื่อนแชทผ่านการ์ดไปแล้ว

ถ้าส่งไม่สำเร็จ (ไม่มี replyToken / token ร้าน) จะบันทึกลง log ตามรูปแบบเดิมและไม่ทำให้ webhook ล้ม

## ไม่แตะต้อง
- `broadcastLineLinked(lineUserId, "followed")` และ logic auto-redirect ฝั่งเว็บ ยังทำงานเหมือนเดิมทุกประการ
- flow ผูกบัญชี / OAuth / RequireLineLink ไม่มีการแก้ไข

## รายละเอียดทางเทคนิค
- ไฟล์ใหม่ `supabase/functions/_shared/followWelcome.ts`
  - `buildFollowWelcomeMessages(origin: string)` — คืน array ข้อความ LINE (flex + quickReply) สไตล์เดียวกับ `adminGroupCommands.ts` (สี PLUM/CREAM, ปุ่ม uri)
  - origin มาจาก `Deno.env.get("PUBLIC_APP_ORIGIN") || "https://filmyynatta.com"` เหมือนที่ webhook ใช้อยู่แล้ว
- `supabase/functions/line-webhook/index.ts` ในบล็อก `ev.type === "follow"`: เรียก `replyLineMessages(LINE_TOKEN, replyToken, buildFollowWelcomeMessages(origin))` ก่อน/หลัง broadcast แล้วเก็บผลลง `logEvent` (`follow — welcome sent` / `welcome failed`)
- deploy edge function หลังแก้

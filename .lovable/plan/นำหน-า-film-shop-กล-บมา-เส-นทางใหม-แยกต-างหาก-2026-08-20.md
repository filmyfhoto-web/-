# นำหน้า FILM SHOP กลับมา (เส้นทางใหม่แยกต่างหาก)

นำหน้าแดชบอร์ดร้าน FILM SHOP ตามภาพอ้างอิงกลับมาใช้งาน โดยไม่กระทบหน้าแดชบอร์ดแอดมิน `/admin/home` และไม่แตะเอกสาร 2 ร้าน / บอท LINE / คิวงาน / POS engine

## เส้นทางใหม่

- เพิ่มเส้นทาง `/film-shop` (หน้าแรกของร้าน FILM SHOP ตามภาพ) และ `/film-shop/*` สำหรับหน้างานย่อยเดิม
- คงสิทธิ์เดิม: ครอบด้วย `RequireStaffAny` เหมือน `/receipts/film/*` ปัจจุบัน
- `/receipts/film` ยัง redirect ไป `/admin/home` ตามเดิม (ไม่เปลี่ยน) ส่วน deep link `?p=...` เดิมยังใช้ได้
- `/admin/home` ยังเป็นแดชบอร์ดแอดมินปัจจุบัน ไม่แก้

## หน้าตาของหน้า (ตามภาพอ้างอิง)

- Sidebar navy gradient 272px: แบรนด์ `FS / FILM SHOP · NATTA GROUP`, ปุ่มม่วง `+ สร้างออเดอร์ใหม่`, เมนู 3 หมวด (งานของฉัน / จัดการงาน / ข้อมูลร้าน), การ์ดแนะนำฟีเจอร์ และแถบผู้ใช้ด้านล่าง
- Header ขาว: ทักทาย `สวัสดีค่ะ, …`, ตัวเลือกร้าน, pill ● ออนไลน์ + เวลา, กระดิ่งพร้อม badge, avatar
- Hero gradient ม่วง–ชมพู: 4 ตัวเลข (งานทั้งหมด / กำลังดำเนินการ / รอตรวจสอบ / รอจัดส่ง) + การ์ด “งานใหม่วันนี้” พร้อม mini line chart
- ทางลัด 5 ใบ: สร้างออเดอร์ใหม่, POS หน้าร้าน, สินค้า/สต๊อก, งานวันนี้, ลูกค้า
- แถวล่าง: “งานล่าสุด” 5 รายการ (เลขที่ / ลูกค้า / เวลา / สถานะ) และ “สรุปงานวันนี้” donut + สัดส่วนสถานะ + เวลาทำงานเฉลี่ย / คาดว่าจะเสร็จ
- ใช้ข้อมูลจริงจาก hook ของร้านที่มีอยู่ (`useFilmOrders` / `useAppData` / workcenter) ไม่ใส่ตัวเลขปลอม มี skeleton ตอนโหลดและ empty state เมื่อไม่มีข้อมูล
- Responsive: tablet ยุบ sidebar เป็น rail/drawer, mobile ใช้ header กะทัดรัด + hero 2×2 + ทางลัด 2 คอลัมน์

## ลิงก์กลับเข้าหน้า

- เพิ่มเมนู/การ์ด “FILM SHOP” กลับเข้าเมนูหลักแอดมิน และการ์ดในหน้าเลือกร้าน `/receipts` ชี้ไป `/film-shop`
- เพิ่มตัวเลือก “FILM SHOP” กลับใน staff landing preference
- ทุกปุ่มในหน้าใหม่ต้องนำทางไป route จริงที่มีอยู่ (ไม่มีปุ่มหลอก)

## ไฟล์ที่จะแก้/เพิ่ม

- `src/App.tsx` — เพิ่ม route `/film-shop` และ `/film-shop/*`
- `src/pages/film-shop/FilmShopHome.tsx` (ใหม่) — หน้าแดชบอร์ดตามภาพ
- `src/components/dashboard/ng/*` — reuse primitives ที่มีอยู่ (metric tile, panel, sparkline)
- `src/film-shop/components/layout/Sidebar.tsx` / `Header.tsx` — ปรับให้ตรงภาพและชี้ base path ใหม่
- `src/lib/adminNav.ts`, `src/pages/receipts/StorePicker.tsx`, `src/lib/staffLanding.ts` — คืนลิงก์เข้า FILM SHOP
- เทสต์: อัปเดต/เพิ่มใน `src/__tests__/` (nav, route registry, dashboard quick links) และ e2e ทางลัด 5 ใบ

## ไม่แตะ

auth/role guards, DB schema, POS checkout engine, เทมเพลต/การคำนวณเอกสาร 2 ร้าน, queue/run-work engine, group bot / LINE backend
